## Offensive Security introduction
This is ethical hacking in the sense of attempting to find weaknesses in a system before real hackers do.

This lesson uses an example finding hidden pages within a bank's wesbite—which then allows for unauthroized administrative access. 

-Using the `dirb` command on the terminal allows for a search of hidden files, pages, or directories.

In this lab's case, a URL for the bank's transfer page came up. You can then, "attack" the page by going to the URL and are free to transfer money from account to account

I have found that this is what as knowns as a "forced browsing attack" which is possible on poorly made systems.
